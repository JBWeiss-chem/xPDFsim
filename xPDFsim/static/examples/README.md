# Example structures

Ten structures from the [Crystallography Open Database](https://www.crystallography.net/cod/) (COD),
selected as classic examples of inorganic, organic and hybrid (metal–organic) materials. The files
are COD entries; `catalog.json` lists their COD numbers and original publications. They are
unchanged except for ZIF-4 (COD 7237205), from which the DMF molecules in the pores were removed
(see the comment at the top of the file).

All COD data have been placed in the public domain by their contributors; please cite the original publications and the COD
(Gražulis et al., Nucleic Acids Res. 40, D420–D427, 2012) when you use them.
